2. Five-Stage Autonomous Bug-Fixing Architecture

Stage Module Engineering Mechanism & Design Guarantee
Stage 1: AST Fault Localization ast_localizer.py & skills/ast_swe_toolkit Indexes Python ast classes, methods, functions, imports, and call edges; fuses innermost stacktrace weighting, BM25 sub-token IDF, and 2-hop call-graph propagation while keeping test files strictly separated as read-only targets.
Stage 2: Minimal Context Slicing context_slicer.py Constructs token-budgeted, line-numbered (L0001:) slices containing imports, enclosing class header, focal function body, 1-hop caller/callee signatures, and linked test expectations—eliminating whole-file context bloat inside 32K/128K windows.
Stage 3: Multi-Candidate Synthesis gemma4_runtime.py Supports vLLM (--reasoning-parser gemma4 --tool-call-parser gemma4), Transformers+PEFT QLoRA, and CPU deterministic runtime across stratified arms (surgical_greedy, boundary_guard, state_invariant) with unified diff and SEARCH/REPLACE extraction.
Stage 4: Self-Refinement & Regression Guard diff_engine.py & patch_pipeline.py Blocks path traversal, enforces ast.parse() syntax validity, rejects edits to test files (allow_test_edits=False), executes target + regression suites inside isolated temp copies, and feeds compact traceback deltas into refinement rounds.
Stage 5: Deterministic Patch Ranking DeterministicPatchRanker Ranks candidates via strict lexicographic order: policy_compliant > syntax_valid > target_pass > zero_regressions > pass_ratio > loc_aligned > -blast_radius > -sha256.
